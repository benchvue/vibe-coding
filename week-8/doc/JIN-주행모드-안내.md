## 2. 화면 구성

**설정 패널 (오른쪽 `설정 ▶`) · 주행 위치**
- `BIN · JIN 보기` — 두 사람 위치 표시
- **BIN / JIN** — 카메라가 따라갈 사람. **JIN 을 누르세요.** 기억됩니다.
- **네비게이션 주행 모드** — 켜면 주행 화면으로
- 바탕 지도: 그린 지도(OSM) / 위성 · 지도 보기: 2D / 3D · 화면 절전 (기본 켬)

**통계 패널 (왼쪽 `◀ 통계`) · DAY 0 카드** — 시험용
- GPX 넣기: 폰 파일 · 드라이브 · 노선 DAY n
- ▶ 재생 · 속도 · 슬라이더 · `주행 모드로 보기` · `궤적 보기`
- 탈것 (자전거/자동차) · 예측 오차 로그 (내려받기·공유 / 지우기)

**주행 화면 (HUD)**
```
[BIN][JIN]  [12.34 km (38 %) / 수신 3분 전 (6:02 pm) · 18 km/h]  [주행 끝]
[📍 ▸ 120 m]                                    ← 명소 단추 (누르면 4개 펼침)
                    (지도 · 위쪽이 진행 방향)
 N↑                                                 [＋]
                                                   500 m
                                                    [－]
              ● 자전거 (300 m 노란 점선 원)
[DAY 0 시험 주행] [실시간 위치 · 방금 (6:58 pm)]
      주행 0:23:14 · 수신 21회 · 오차 2.318 %
```
- 손가락으로 지도를 돌리거나 끌 수 없습니다. **＋ / －** 만 (60 m ~ 64 km).
- 보라색 점선 원 = 마지막 수신 자리, 보라색 굵은 선 = 거기서 지금 추정 자리까지.

## 3. 한국에서 시험하는 순서

### 3-1. 궤적 준비
1. 동네 한 바퀴를 자전거로 타면서 **Strava / Garmin / 아무 앱**으로 기록 → GPX 내보내기 (시간 포함되게).
2. (선택) 명소 넣기 — gpx.studio 에서 GPX 열고 **Waypoint(📍)** 도구로 지점 클릭 → Name(원어) · Description(한글 설명) · Symbol 입력 → Export.
   Symbol 에 쓸 수 있는 값: `Church` `Restaurant` `Bar` `Lodging` `Scenic Area` `Summit` `Flag` `Water` `Bridge` `Bike Shop` `Museum` `Park` `Shop` `Danger` `Toilet`
3. 그 GPX 를 **드라이브 공유 폴더**에 올림 (폰 파일 선택기에서 .gpx 가 회색이면 이 길이 확실).

### 3-2. 페이지에서
1. 통계 → DAY 0 → **드라이브에서 고르기** → 파일 선택. 카드에 `거리 · 점 · 명소 N` 이 뜨면 읽힌 것. 브라우저가 기억하니 다음엔 안 골라도 됩니다.
2. 설정 → **JIN** 선택.
3. **먼저 책상에서**: DAY 0 카드 ▶ 재생, 20× → `주행 모드로 보기`. 📍 단추 눌러 **음성 안내** 체크. 명소마다 삐 + 한국어 음성 + 화면 아래 노란 띠가 뜨는지 확인. 지나치면 회색 `방금 지나침` 으로 바뀝니다.
4. **실제로 타기**: OwnTracks Move 모드 → 페이지 주행 모드 → 아래 띠 **실시간 위치** 선택 → 폰을 거치대에 두고 **화면 켠 채** 출발.
   - 화면이 꺼지면 iOS 가 OwnTracks 전송을 막아 위치가 몇 분씩 늦어집니다.
   - 위치는 3분(시험 땐 1분)마다 오고, 그 사이는 **속도와 경사로 추정**해서 표지를 밀어 줍니다.
5. 완주하면 위쪽에 **완주 · 예측 오차 N %** 요약이 뜹니다.

### 3-3. 끝나면 BIN 에게 보낼 것
- DAY 0 카드 → **로그 내려받기 · 공유** → 카톡으로 `pred-log-jin-날짜.json`
- 그날 탄 **GPX**
- 이 둘로 추정 알고리즘을 고칩니다. 오차율은 "수신마다 |추정 위치 − 실제 위치| 를 더한 것 ÷ 주행 거리".

## 4. 잘 안 될 때

| 증상 | 확인 |
|---|---|
| 판 번호가 옛것 | 주소 끝 `?v=` 숫자 바꿔 열기 · Safari 로 열기 |
| 실시간 위치가 안 바뀜 | OwnTracks Status Info 에 에러가 있는지 · URL 에 `workers.dev` s 확인 · monitoring 이 0 아닌지 |
| 자전거가 궤적 위가 아닌 엉뚱한 곳 | 궤적에서 400 m 넘게 떨어지면 "궤적 위" 표시가 풀리고 실제 좌표로 감 |
| 명소가 목록에 안 뜸 | 자전거 길에서 400 m 넘게 떨어진 명소는 안 나옴 |
| 소리가 안 남 | 무음 스위치 · 음성 체크박스 · 첫 알림은 화면을 한 번 탭한 뒤에야 남 (iOS 규칙) |
| 폰이 뜨거움 | 설정 → 화면 절전 켜기 · 2D + 그린 지도 · 밝기 낮추기 · 5G 대신 LTE · 충전하며 쓰지 않기 |
